# WordBolder (FocusRead)

A Chrome extension designed to make reading web pages faster, easier, and more comfortable using bionic reading techniques and visual focus aids.

## Features

- **Word Styling**:
  - **Bold Word Beginnings**: Emphasize the first 1–4 letters of words to guide eye fixation and improve reading speed (bionic reading).
  - **Colour Word Beginnings**: Highlight initial letters with subtle accent colours (Calm Blue, Soft Purple, Teal, Warm Coral).
- **Comfortable Text**:
  - Customizable text font size (18px, 20px, 22px).
  - Adjustable line spacing (Comfortable, Extra space, Very spacious).
  - Extra paragraph spacing to separate dense blocks of text.
  - Narrow reading width to keep long lines shorter and reduce eye fatigue.
- **Stay on Track**:
  - **Reading Line Guide**: A horizontal guide ruler that follows your cursor across the page.
  - **Paragraph Focus**: Highlight the active paragraph under your cursor.
  - **Reading Time Estimate**: Calculate estimated reading time and word count for the current page (based on 200 words/min).
  - **Read Aloud**: Listen to page text using the browser's built-in text-to-speech engine.

## Installation

1. Clone or download this repository:
   `ash
   git clone https://github.com/KhanAdilKM/WordBolder.git
   `
2. Open Google Chrome (or any Chromium browser like Edge/Brave) and navigate to:
   `
   chrome://extensions/
   `
3. Enable **Developer mode** using the toggle switch in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the repository directory.
6. The extension is now installed! Pin it to your Chrome toolbar for quick access.
